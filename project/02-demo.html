Step 01 · Trigger

Lead arrives from ad

Facebook Lead Ad or Instagram DM triggers the n8n webhook. The conversation thread is opened, the lead's number is logged to Airtable.

Trigger: Facebook Lead Ad → n8n webhook → Airtable row created
Step 02 · Engage

AI replies in <10 seconds

GPT-4 fires the opening message with the clinic name injected. This is the moment that wins the lead. Show the timestamp gap on Loom.

Node: HTTP Request → WhatsApp Business API
Prompt: greeting + menu options (numbered for simple replies)
Step 03 · Qualify

Four structured questions

Area → Experience → Budget → Timing. Each answer routes the conversation branch. Budget under $200 flags as low-priority; "just browsing" enters the nurture sequence.

Node: Switch node on reply content
CRM: Update Airtable fields: area, experience, budget, intent
Step 04 · Book

Slot selection → calendar write

Available slots pulled from Google Calendar in real time. Lead picks one by replying a number. n8n creates the event and sends confirmation immediately.

Node: Google Calendar API → create event
Node: WhatsApp → confirmation template message
Step 05 · Remind

Automated 24hr reminder

A scheduled n8n workflow fires the reminder message 24 hours before the appointment time. CANCEL/RESCHEDULE keywords trigger a rebooking flow.

Node: Schedule trigger → filter upcoming events
Node: WhatsApp → reminder template

If the lead goes quiet: the follow-up sequence.

Three escalating touchpoints if a lead enquires but doesn't book. Fully automated; no manual action needed.
